# CamLag

Fake a bad connection on demand: realistic video and mic lag, freezes and loops for any video call on Windows.

**Download:** grab `CamLag.exe` from the [latest release](../../releases/latest).

**Website:** https://camlag.netlify.app

## Before you start
1. Install [OBS Studio](https://obsproject.com/download) (free). It provides the virtual camera.
2. Install [VB-Cable](https://vb-audio.com/Cable/) (free), then restart your PC. It provides the virtual microphone.
3. Open `CamLag.exe` and create a free account.

If Windows shows "Windows protected your PC", click **More info**, then **Run anyway**.

Windows 10 and 11, 64-bit.
